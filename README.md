# جرجبيتا — الواجهة (Next.js 15 + Tailwind v4)

واجهة مطعم **جرجبيتا** (أسوان): منيو المطعم + منيو المصنعات، سلة طلبات تُرسل إلى
**واتساب**، معرض صور وفيديوهات، ولوحة تحكم كاملة لكل شيء.

نفس تقنيات مشروع أشكناني: **Next.js 15 (App Router) + React 18 + TypeScript +
Tailwind CSS v4 + shadcn/Radix + lucide-react + sonner**، والباك-إند **HonoJS على
Cloudflare Workers + D1** (مجلد `backend/`).

## التشغيل

```powershell
cd frontend
npm install
npm run dev          #  http://localhost:3000
npm run typecheck    #  فحص الأنواع
npm run build        #  بناء الإنتاج
```

لربط الواجهة بالـ API:

```powershell
$env:NEXT_PUBLIC_API_BASE_URL = "http://localhost:8787"   # أو رابط Worker المنشور
```

> إذا لم يعمل الـ API، يعمل الموقع كاملًا من `lib/fallback-data.ts` (نفس بيانات `backend/seed.sql`).

## الصور (مهم)
كل الصور الحالية **رسومات معاينة** موجودة في `public/images/` (أسماء تبدأ بـ `ph-`)
حتى لا يظهر أي عنصر بلا صورة. لاستبدالها بصور حقيقية:

1. **من لوحة التحكم** (الأسهل، ولا يحتاج نشر من جديد): الإعدادات ← الشعار / صورة
   الهيرو، والوسائط ← رفع صورة، والأصناف/Aقسام ← حقل الصورة. الملف يُخزَّن في
   قاعدة البيانات ويُنسخ رابطه تلقائيًا في الحقل.
2. **أو يدويًا**: انسخ صورك داخل `frontend/public/images/` ثم ضع مسارها مثل
   `/images/logo.jpeg` في نفس الحقول.

للشعار المحدد من WhatsApp: انسخ الملف إلى
`frontend/public/images/logo.jpeg` ثم ضع `/images/logo.jpeg` في حقل «الشعار»
(أو ارفعه من اللوحة مباشرة). حاليًا الشعار الافتراضي `public/images/logo.svg`
رسمة مؤقتة بنفس ألوان الهوية.

## الأقسام في الواجهة
- `#home` الهيرو: الشعار، العنوان، أزرار «اطلب على الواتساب» و«شوف المنيو» + 3 مزايا.
- المنيو: لوحتان (المطعم / المصنعات) + أفضل الأصناف.
- `#gallery` المعرض: فلترة (الكل/صور/فيديوهات) + عرض الصور في نافذة + تشغيل يوتيوب.
- `#about` و`#contact`: نبذة + بيانات التواصل والخريطة والواتساب.
- `/menu`: تبويبا القسمين + بحث + فلترة بالأقسام + إضافة للسلة.
- السلة: شريط جانبي، حفظ في المتصفح، نموذج (اسم/هاتف/منطقة/عنوان/ملاحظات) ثم إرسال واتساب.
